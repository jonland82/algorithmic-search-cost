two notes on order, information, and search

how much does order buy?

jonathan r. landers

an array can be nearly sorted without telling us where its disorder lies. the first note asks what a bound on disorder alone can guarantee. the second asks what changes when we can compare keys once and reuse what we learn across many searches.

the shared measure

\[V(A)=\frac12\sum_{i=1}^{n}\bigl(\operatorname{rank}_A(a_i)-i\bigr)^2\]

01   /   one search

disorder potential and the cost of search

a limit \(V(A)\le E\) bounds how far a key can sit from its sorted position. a modified binary search ends with a short scan; a hidden minimum shows that the scan can be necessary.

tight worst-case cost

\[Q^*(n,E)=\Theta\!\left(\log n+\min\{n,\sqrt E\}\right)\]

families with the same potential budget can place disorder differently, so the budget alone does not describe every useful search feature.

02   /   repeated search

search under a disorder budget

for \(q\) searches on one fixed array, preprocessing becomes an investment. we can search each time, or build a sorted index using the displacement bound and share it across queries.

a reusable upper bound

\[T_q^*(n,E)=O\!\left(q\log n+\min\{qR_E,\;n\log(R_E+1)\}\right)\]

here \(R_E=1+D_E\), with \(D_E\) the largest displacement allowed by \(E\). learned hints can help when comparisons verify the structure they claim.

the through line

disorder limits what search must face. location information determines what search can exploit. preprocessing is worthwhile when its cost is paid back by the searches that follow.
