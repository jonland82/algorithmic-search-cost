\begin{center}
{\Large\bfseries Search Under a Disorder Budget}\\[2pt]
{\small A note on preprocessing, repeated queries, and learned structure}\\[5pt]
Jonathan R. Landers \qquad October 7, 2026
\end{center}

The paper \emph{Disorder Potential and the Cost of Search} asks what a single
search can gain from knowing how far an array lies from sorted order.
Its answer has a square-root term: a potential budget of size $E$ permits
a key to hide among roughly $\sqrt E$ positions. Repeated searches change
the question. Comparisons spent once on the fixed array can create an
index that later targets share. Here $E$ limits the input's disorder;
a separate budget $B$ pays for learning its structure.

\paragraph{The one-query starting point.}
Let $A=(a_1,\ldots,a_n)$ contain distinct keys, and let
$x_i=\operatorname{rank}_A(a_i)$. The rank word $x$ is a vertex of the
permutohedron; sorted order is $(1,\ldots,n)$. The paper uses
\[
 V(A)=\frac12\sum_{i=1}^n(x_i-i)^2,\qquad
 d(A)=\max_i|x_i-i|,\qquad V(A)\le E .
\]
Set
\[
 D_E=\min\left\{n-1,
 \left\lfloor\frac{\sqrt{1+8E}-1}{2}\right\rfloor\right\},
 \qquad R_E=D_E+1 .
\]
The displacement lemma gives $d(A)\le D_E$: if one displacement has
magnitude $d$, the others have total absolute displacement at least $d$,
because $\sum_i(x_i-i)=0$. Since displacements are integers,
$2V(A)\ge d^2+d$. Thus $R_E=\Theta(1+\min\{n,\sqrt E\})$.

A target query compares $y$ with entries $a_i$ and returns its index or
absence. With no preprocessing, the paper proves a worst-case cost
$\Theta(\log n+R_E)$. For the upper bound, a midpoint comparison narrows
the possible target positions up to a margin of $2D_E$; when only
$O(D_E+1)$ positions remain, scan them. The lower bound moves a new
minimum to position $j$: the resulting rank word
$(2,\ldots,j,1,j+1,\ldots,n)$ has potential $j(j-1)/2$, so every
$j\le R_E$ is a possible hiding place.

\paragraph{What preprocessing may buy.}
Now keep the same array for $q\ge1$ target searches. Before the first
target, preprocessing may compare array keys and retain an $O(n)$-word
index. Count those comparisons and all later target-to-entry comparisons;
the promise $V(A)\le E$ remains free, as in the paper. The optimization is
\[
 T_q^*(n,E)=\inf_{P,S}\ \sup_{\substack{A:\,V(A)\le E\\y_1,\ldots,y_q}}
 \left[C_P(A)+\sum_{t=1}^q C_S(y_t\mid A,P,\mathcal H_{t-1})\right],
\]
over correct methods using $O(n)$ storage; $\mathcal H_{t-1}$ is the retained search history. A useful accounting form is
\[
 \text{total cost}
 \;\le\; B+O\!\left(q(\log n+W)\right),
 \tag{1}
\]
whenever $B$ preprocessing comparisons produce a verified search
structure with per-query residual work at most $W$ beyond binary-search
depth. The structure and its verification determine $W$; a prediction
alone does not.

\begin{theorem}[Preprocessing bound]
For $n\ge2$, $E\ge0$, and $q\ge1$,
\[
 \boxed{\displaystyle
 T_q^*(n,E)=
 O\!\left(q\log n+
       \min\{qR_E,\;n\log(R_E+1)\}\right).}
 \tag{2}
\]
\end{theorem}

The minimum compares two concrete choices of preprocessing budget.

\newpage
\paragraph{Proof of the bound.}
One choice is $B=0$: use the paper's bounded-displacement search
independently for each target. This costs
$O(q\log n+qR_E)$.

For the other choice, construct a sorted index of the array positions.
The displacement bound says that the key of rank $k$ occurs by position
$k+D_E$. Start a min-heap with positions
$1,\ldots,\min\{n,D_E+1\}$. Repeatedly remove its minimum and insert the
next unread position, if any. Before the $k$th removal, the heap contains
every unread position among the first $\min\{n,k+D_E\}$ positions.
In particular it contains rank $k$, whose position is at most $k+D_E$;
the extracted key is therefore rank $k$. A heap of at most $D_E+1=R_E$
entries costs $O(n\log(R_E+1))$ comparisons and yields an $O(n)$-word
array of positions in key order. Ordinary binary search on that index
then costs $O(\log n)$ comparisons per target. Choosing the cheaper
strategy proves (2). \hfill$\square$

The crossover is $qR_E\asymp n\log(R_E+1)$, up to constant factors.
For small $q$, the original search is economical; for enough queries,
paying once for the index removes the recurring displacement scan.
When $E=0$, the promise already gives sorted order. When $R_E=n$,
the index construction has the familiar $O(n\log n)$ cost.

\paragraph{Why remembered search outcomes are weaker.}
Suppose there is no array-to-array preprocessing and memory retains
only previous target-to-entry signs. Even this persistent memory cannot
remove the $qR_E$ term in the worst case. Run the algorithm on a sorted
array $a_1<\cdots<a_n$ with increasing absent targets
$y_1<\cdots<y_q<a_1$. In round $t$, for each $j\le R_E$, compare this
history with the fixed alternative array that replaces $a_j$ by $y_t$.
That alternative has potential $j(j-1)/2\le E$. Every earlier target
is below $y_t$, so all earlier comparison signs agree with those on the
sorted array. Unless round $t$ queries position $j$, its signs agree
as well, yet its correct answer is $j$ rather than absence.
Every one of the first $R_E$ positions must therefore be queried in
every round: $\Omega(qR_E)$ target comparisons. The argument concerns
sign-only search histories; the sorted-index strategy uses the stronger
array comparisons allowed during preprocessing.

\paragraph{Where a learned certificate fits.}
A learned rule can propose a family of likely key locations, a small
displacement limit, or a partial index. Its cost enters through $B$,
including the comparisons needed to \emph{verify} a guarantee usable by
search. For example, if preprocessing certifies $d(A)\le D'$ after
$B$ comparisons, the paper's search argument gives
\[
 \text{total cost}
 \le B+O\!\left(q\log n+q(D'+1)\right).
 \tag{3}
\]
This is an instance-dependent improvement when the saved scan work
amortizes $B$. For example, a prediction that $A$ is sorted can be
checked with $n-1$ adjacent comparisons; on success $D'=0$.
On failure, use the baseline. A certificate of $D'<D_E$ is not
guaranteed over every
array with $V(A)\le E$: some allowed arrays attain $d(A)=D_E$.
The unconditional result is (2). A sharper worst-case guarantee from
learning needs a stated, verified restriction on the arrays or their
possible target locations.
